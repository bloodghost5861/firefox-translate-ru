# Перевод страницы на русский

Расширение для Firefox (Android и компьютер). Добавляет на каждую страницу плавающую кнопку:
одно нажатие — текст страницы переводится на русский, повторное — возвращается оригинал.
Кнопку можно перетаскивать и менять её размер, а по удержанию открываются настройки.
При прокрутке страницы вниз кнопка прячется, при прокрутке вверх — возвращается (можно отключить в настройках).

Требования: **Firefox 142+** (компьютер) или **Firefox для Android 142+**.
Минимальная версия связана с обязательным объявлением о сборе данных для AMO (см. раздел «Приватность»).

```
┌───────────────────────────────┐
│  Article text in English...   │
│                               │
│                     ╭─────╮   │
│                     │ RU  │ ← плавающая кнопка
│                     ╰─────╯   │
└───────────────────────────────┘
```

## Что умеет

- Переводит **текст страницы**, а не всю страницу целиком: разметка, ссылки, картинки и вёрстка остаются на месте.
- Одно нажатие — перевод, второе — возврат оригинала (перевод не разрушает страницу).
- Плавающая кнопка: перетаскивается, позиция запоминается, размер меняется в настройках (40–72 px), не мешает странице (изолирована в Shadow DOM).
- При прокрутке вниз кнопка скрывается, при прокрутке вверх — появляется снова.
- Прогресс перевода в процентах прямо на кнопке, перевод можно прервать повторным нажатием.
- Удержание кнопки — панель настроек: сервис перевода, языки, ключи API.
- Три сервиса на выбор: **Google** (без ключа, по умолчанию), **DeepL** (ключ API), **LibreTranslate** (свой сервер).
- Не переводит код, поля ввода и скрытые блоки; не трогает страницу, если она уже на русском (можно отключить).
- Никакой телеметрии и внешних скриптов: только запросы к выбранному сервису перевода.

## Установка

### 1. Быстрая проверка на компьютере (2 минуты)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение…»** и выберите `manifest.json` из папки `firefox-translate-ru`.
3. Откройте тестовую страницу. Лучше через локальный сервер, чтобы работали все права:

   ```bash
   cd firefox-translate-ru
   python -m http.server 8000
   ```

   Затем откройте <http://localhost:8000/test/demo.html>.
4. Нажмите кнопку **RU** в правом нижнем углу.

Временное дополнение живёт до перезапуска Firefox — это нормально для проверки.

### 2. Firefox для Android

В стабильном Firefox для Android расширения ставятся **с addons.mozilla.org** (подписанные).
Установка произвольного `.xpi` из файла в мобильной версии, как правило, недоступна.

**Вариант A. Через AMO (постоянная установка, рекомендуется)**

1. Соберите zip (см. ниже) или возьмите готовый `firefox-translate-ru.zip`.
2. Войдите в [Developer Hub](https://addons.mozilla.org/developers/) и выберите
   **Submit a New Add-on** → **On your own** (unlisted / самостоятельное распространение).
3. Загрузите zip. AMO проверит и подпишет расширение; в карточке версии скачайте подписанный `.xpi`
   (он же будет доступен по ссылке на странице дополнения).
4. Откройте ссылку на дополнение **на телефоне** в Firefox и нажмите «Add to Firefox».
   Расширение помечено как совместимое с Android (`gecko_android` в манифесте), поэтому установка доступна.
5. Кнопка появится на любой открытой странице; настройки — удержанием кнопки.

> Если AMO пишет, что дополнение несовместимо с Android, проверьте, что в манифесте есть блок
> `browser_specific_settings.gecko_android` (он уже есть) и что в Developer Hub у версии отмечена
> совместимость с Android.

**Вариант B. Отладка на телефоне через web-ext**

Нужны Firefox **Nightly** (или Beta) для Android, включённая отладка по USB и `adb`.

```bash
npx web-ext run --target=firefox-android --android-device=<id-устройства>
```

`web-ext` соберёт расширение, поставит его как временное и перезапустит браузер при изменениях.
Список устройств: `adb devices`.

**Вариант C. Установка из подписанного файла (работает и для unlisted)**

Официальный способ Firefox для Android:

1. Скачайте подписанный `.xpi` на телефон (из письма AMO или из Developer Hub) — файл окажется в «Загрузках».
2. Откройте Firefox → **Настройки** → **О Firefox** (About Firefox).
3. Быстро нажмите на логотип Firefox **пять раз** — появятся скрытые пункты меню.
4. Вернитесь в **Настройки** → **«Установить расширение из файла»** (Install Extension from File).
5. Выберите скачанный `.xpi` → **Добавить**.

Расширение установится постоянно и переживёт перезапуск браузера. При установке из файла Firefox
сам проверяет совместимость с Android по манифесту.

### 3. Сборка zip для AMO

**Не используйте `Compress-Archive`**: на Windows он записывает имена вида `content\main.js`,
и AMO отклоняет архив с ошибкой `Invalid file name in archive`.

Соберите архив с прямыми слэшами:

```powershell
Add-Type -AssemblyName System.IO.Compression
Add-Type -AssemblyName System.IO.Compression.FileSystem
$src = (Resolve-Path .\firefox-translate-ru).Path
$zipPath = Join-Path (Get-Location) 'firefox-translate-ru.zip'
if (Test-Path $zipPath) { Remove-Item $zipPath }
$zip = [System.IO.Compression.ZipFile]::Open($zipPath, 'Create')
Get-ChildItem $src -Recurse -File | ForEach-Object {
  $rel = $_.FullName.Substring($src.Length + 1).Replace('\', '/')
  [System.IO.Compression.ZipFileExtensions]::CreateEntryFromFile($zip, $_.FullName, $rel) | Out-Null
}
$zip.Dispose()
```

Проверьте имена — должны быть `content/main.js`, `icons/icon-48.png`, а не с обратными слэшами:

```powershell
$z = [System.IO.Compression.ZipFile]::OpenRead('.\firefox-translate-ru.zip')
$z.Entries | ForEach-Object { $_.FullName }
$z.Dispose()
```

Важно: `manifest.json` должен лежать **в корне** архива, а не внутри вложенной папки.

## Настройки

Удерживайте кнопку (~0,6 с) — откроется панель:

| Параметр | По умолчанию | Зачем |
|---|---|---|
| Сервис перевода | Google | Google работает без ключа; DeepL и LibreTranslate — варианты на случай лимитов или качества |
| Язык страницы | Авто | Обычно определяется сам; можно указать вручную |
| Переводить на | Русский | Любой язык из списка |
| Размер кнопки | 54 px | От 40 до 72 px, меняется слайдером в настройках |
| Ключ DeepL API | — | Нужен для DeepL. Ключ бесплатного тарифа заканчивается на `:fx` |
| Адрес сервера / ключ LibreTranslate | — | Для своего или публичного сервера LibreTranslate |
| «Переводить, даже если страница уже на русском» | выкл. | Принудительный перевод похожих славянских языков |
| «Скрывать кнопку при прокрутке вниз» | вкл. | Кнопка прячется при скролле вниз и возвращается при скролле вверх |

Настройки, позиция и размер кнопки хранятся в `browser.storage.local` — только в этом браузере, без синхронизации.

## Сервисы перевода

- **Google** — публичный endpoint `translate.googleapis.com` (тот же, что использует встроенный переводчик).
  Ключ не нужен. Это неофициальный API: он может ограничивать частоту запросов (ошибка 429) и меняться без предупреждения.
- **DeepL** — лучшее качество для европейских языков. Нужен ключ API; бесплатный тариф —
  до 500 000 символов в месяц. Текст уходит на `api-free.deepl.com` (для ключей `:fx`) или `api.deepl.com`.
- **LibreTranslate** — открытый переводчик, можно поднять свой сервер (тогда текст никуда не уходит).
  Публичные инстансы часто перегружены, поэтому адрес задаётся вручную.

Расширение отправляет текст пакетами (~1200 символов), последовательно, с небольшой паузой,
чтобы не упираться в лимиты. Одинаковые куски кешируются в памяти фонового скрипта.

## Как это работает

```
content script (страница)                    background (расширение)
┌──────────────────────────┐   сообщение    ┌──────────────────────────┐
│ кнопка в Shadow DOM      │ ─────────────► │ выбор провайдера          │
│ сбор текстовых узлов     │                │ fetch к сервису перевода  │
│ нарезка на пакеты        │ ◄───────────── │ кеш ответов               │
│ подстановка перевода     │   перевод      └──────────────────────────┘
│ возврат оригинала        │
└──────────────────────────┘
```

- Текст собирается обходом DOM (`TreeWalker` по текстовым узлам). Пропускаются `script`, `style`,
  `code`, `pre`, поля ввода, `contenteditable`, скрытые элементы, SVG/MathML и блоки с `translate="no"`.
- Каждый узел запоминается вместе с оригиналом; при возврате восстанавливается ровно исходный текст.
- Запросы делает фоновый скрипт: у него есть права хоста, поэтому CORS и CSP сайта не мешают.
- Длинные абзацы режутся по предложениям, пакеты переводятся по очереди, результат подставляется постепенно.
- Если сервис вернул не то количество строк, включается резервный режим «по одной строке».

## Ограничения

- **Динамический контент.** Уже переведённая страница не следит за новой подгрузкой (бесконечная лента,
  раскрывающиеся блоки): новый текст останется на языке оригинала. Нажмите кнопку дважды, чтобы перевести заново.
  Если сайт полностью подменил содержимое без перезагрузки (SPA), кнопка это заметит и запустит перевод заново;
  частичные обновления страницы так не отслеживаются.
- **Отмена.** Текущий сетевой запрос при отмене не прерывается: перевод остановится после ответа сервиса
  (в худшем случае — по таймауту, около 25 секунд), затем оригинал восстановится.
- **Iframe.** Переводятся только страницы верхнего уровня (`all_frames: false`).
- **Вёрстка.** Русский текст обычно длиннее английского, поэтому возможны сдвиги блоков и обрезание
  текста в кнопках с фиксированной шириной.
- **Закрытые страницы.** На `about:`, страницах AMO, PDF-просмотрщике и внутренних страницах Firefox
  content script не запускается — кнопки там не будет.
- **Неофициальный Google-эндпоинт** может ответить 429 или измениться. В этом случае поможет DeepL
  или свой LibreTranslate.
- **Качество.** Машинный перевод не идеален, особенно для имён, терминов и кода в тексте.

## Приватность

Текст страницы отправляется только выбранному сервису перевода (Google / DeepL / ваш LibreTranslate).
Расширение не собирает статистику, не использует аналитику и не отправляет ничего, кроме текста,
который вы переводите. Ключи API хранятся локально в настройках расширения.

В манифесте это задекларировано для AMO:

```json
"data_collection_permissions": { "required": ["websiteContent"] }
```

С ноября 2025 года AMO требует такое объявление от новых расширений, поэтому при установке
Firefox может показать встроенное окно согласия на передачу содержимого страниц.

## Проверка

Что проверено автоматически (скрипты лежат в соседней папке `tools/` и в пакет не входят):

- синтаксис всех JS-файлов и валидность манифеста;
- реальный запрос к Google: пакет из трёх строк переводится построчно (Node);
- фоновый скрипт: приём сообщения, ответ, кэш и понятная ошибка при отсутствии ключа DeepL;
- запуск расширения в **настоящем Firefox 145** (headless, временная установка): кнопка появляется,
  текст реально переводится на русский, повторное нажатие возвращает оригинал, удержание открывает настройки;
- установка на реальном **Android** (Samsung Galaxy S24 Ultra, Firefox 158.0.2) по Wi-Fi ADB:
  кнопка появляется, перевод Google работает, прогресс отображается, возврат оригинала работает;
- страница со строгой Content-Security-Policy (`style-src 'self'`): стили кнопки в Shadow DOM не блокируются,
  перевод продолжает работать;
- UI-сценарий (кнопка, возврат, панель настроек, перетаскивание) в Chromium;
- смена размера кнопки слайдером (40–72 px) и сохранение размера в `storage` — Chromium;
- скрытие кнопки при прокрутке вниз и возврат при прокрутке вверх — Chromium и Firefox.

Что не проверялось: работа DeepL и LibreTranslate с настоящими ключами.

## Структура

```
firefox-translate-ru/
├── manifest.json          манифест (Manifest V2, совместим с Firefox для Android)
├── background.js          настройки, кэш, приём сообщений
├── lib/
│   └── providers.js       Google / DeepL / LibreTranslate (без browser.* — можно тестировать в Node)
├── content/
│   ├── text.js            сбор текста, нарезка, подстановка, возврат оригинала
│   ├── ui.js              плавающая кнопка, тосты, панель настроек (Shadow DOM)
│   └── main.js            сценарий: нажатие → перевод → возврат
├── icons/icon.svg         иконка
├── test/demo.html         тестовая страница
├── LICENSE                MIT
└── README.md
```

Проверить логику провайдеров без браузера:

```bash
node -e "require('./lib/providers.js');globalThis.DSHTranslate.translate(['Hello world'],{provider:'google',target:'ru'}).then(r=>console.log(r))"
```
