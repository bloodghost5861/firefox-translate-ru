**Одно нажатие — страница по-русски.**

«Перевод страницы на русский» добавляет на каждую страницу небольшую плавающую кнопку. Нажали — текст страницы переводится на русский, нажали ещё раз — возвращается оригинал. Кнопку можно перетащить в удобное место и изменить её размер, а удержание открывает настройки. При прокрутке страницы вниз кнопка прячется, при прокрутке вверх — возвращается, чтобы не мешать чтению.

**Как это работает**

- Переводятся только текстовые блоки: заголовки, абзацы, списки, подписи. Вёрстка, ссылки, картинки и таблицы остаются на месте.
- На кнопке виден прогресс, перевод можно прервать повторным нажатием.
- Код, поля ввода, скрытые блоки и служебные элементы не переводятся.
- Если страница уже на русском, расширение так и скажет — и не потратит запросы.

**Три сервиса на выбор**

| Сервис | Ключ | Комментарий |
|---|---|---|
| Google | не нужен | работает сразу, по умолчанию |
| DeepL | ключ API | лучшее качество для европейских языков, есть бесплатный тариф |
| LibreTranslate | адрес сервера | можно поднять свой сервер, тогда текст не уходит третьим лицам |

Язык страницы определяется автоматически (можно указать вручную), язык перевода по умолчанию — русский, но его можно сменить.

**Настройки**

Удерживайте кнопку около секунды: откроется панель, где выбираются сервис, языки и ключи, а также размер кнопки (40–72 px). Там же есть переключатели «Переводить, даже если страница уже на русском» и «Скрывать кнопку при прокрутке вниз». Настройки, позиция и размер кнопки хранятся только в вашем браузере.

**Приватность**

Расширение не собирает статистику, не использует аналитику и не имеет собственного сервера. Текст страницы отправляется только выбранному вами сервису перевода: Google, DeepL или вашему LibreTranslate. Ключи API хранятся локально. Подробнее — в политике приватности.

**Совместимость**

- Firefox 142+ на компьютере.
- Firefox для Android 142+.
- Manifest V2, без удалённого кода и без сторонних библиотек.

**Ограничения**

- Новый контент, который подгружается уже после перевода (бесконечная лента, раскрывающиеся блоки), не переводится автоматически.
- Iframe, canvas и закрытый Shadow DOM не затрагиваются.
- Русский текст обычно длиннее английского, поэтому возможны небольшие сдвиги вёрстки.
- Публичный Google-эндпоинт неофициальный и иногда ограничивает частоту запросов — на этот случай есть DeepL и LibreTranslate.
