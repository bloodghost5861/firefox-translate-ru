# Notes to reviewer

Скопируйте этот текст в поле **Notes to reviewer** (или в заметки к версии).

---

**Что делает расширение**

Добавляет на страницы плавающую кнопку. По нажатию переводит текстовые узлы страницы на русский
(по умолчанию) и по повторному нажатию возвращает исходный текст. Языки и сервис перевода
настраиваются в панели, которая открывается удержанием кнопки.

**Manifest V2, Firefox 142+**

Используется Manifest V2 с `background.scripts` (не service worker) — так расширение одинаково
работает в Firefox для компьютера и в Firefox для Android. `browser_specific_settings.gecko_android`
включён, поэтому дополнение доступно и на Android.

**Разрешения и зачем они**

- `storage` — настройки (сервис, языки, ключи API) и позиция кнопки. Всё хранится локально.
- `<all_urls>` — две вещи:
  1. content script должен уметь добавлять кнопку на любую страницу, которую пользователь решил перевести;
  2. фоновый скрипт делает запросы к сервису перевода, в том числе к **пользовательскому** адресу
     LibreTranslate, который заранее неизвестен. Список хостов ограничить нельзя, поэтому запрошен
     широкий host permission. Других сетевых запросов расширение не делает.

**Сеть и данные**

- Запросы идут только на выбранный сервис:
  `https://translate.googleapis.com/translate_a/single` (Google),
  `https://api-free.deepl.com/v2/translate` или `https://api.deepl.com/v2/translate` (DeepL),
  `<адрес пользователя>/translate` (LibreTranslate).
- Передаётся только текст страницы, который пользователь решил перевести, и коды языков.
- Нет собственного сервера, аналитики, телеметрии, рекламы и удалённого кода.
- `eval`, `new Function`, загрузка внешних скриптов и присваивание `innerHTML` не используются.
  Разметка интерфейса — статическая строка, которая разбирается через `DOMParser` и вставляется
  в Shadow DOM; пользовательские данные в HTML не подставляются. Весь код находится в пакете,
  сторонних библиотек нет.
- `data_collection_permissions.required = ["websiteContent"]` — заявлено в манифесте.

**Как проверить за пару минут**

1. Установите дополнение (временная установка подойдёт).
2. Откройте любую англоязычную страницу, например
   <https://www.gnu.org/philosophy/free-sw.en.html>.
3. В правом нижнем углу появится круглая кнопка **RU**. Нажмите её: текст станет русским,
   на кнопке будет виден прогресс, затем кнопка станет зелёной со значком **↺**.
4. Нажмите **↺** — вернётся исходный английский текст.
5. Удерживайте кнопку ~1 секунду — откроется панель настроек (сервис, языки, ключи).
6. В пакете есть тестовая страница `test/demo.html` — её можно открыть локально и проверить то же самое.

**Ожидаемое поведение на служебных страницах**

На `about:`, страницах AMO, PDF-просмотрщике и внутренних страницах Firefox content script не запускается —
кнопки там нет, это нормально.

**Замечания**

- Публичный Google-эндпоинт неофициальный; при 429 расширение показывает понятную ошибку и предлагает
  сменить сервис. Это не скрытый канал: URL и формат запроса видны в `lib/providers.js`.
- Расширение не претендует на обход ограничений сайтов: если сайт запрещает вставку UI (например,
  закрытый Shadow DOM или canvas), текст просто не переводится.
